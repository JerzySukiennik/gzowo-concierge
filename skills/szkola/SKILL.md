School events live in the iCloud calendar named "!SZKOŁA". Use calendar_list / calendar_add with calendar "!SZKOŁA".

Title convention, Polish, short: "<Przedmiot> <temat> <typ>", for example "Biologia Wodorotlenki Sprawdzian", "Hiszpański Ser-Estar-Vivir Kartkówka", "J.Polski Wypracowanie Folwark Zwierzęcy". Types: Sprawdzian, Kartkówka, Poprawa, Wypracowanie, Projekt, Zadanie. Subject abbreviations he already uses: J.Polski, Biologia, Geografia, Hiszpański.

When he mentions a test, quiz or deadline:
1. Extract subject, topic, type, date. If the lesson hour is missing, ask once ("o której lekcji?") instead of guessing.
2. Before adding, list that day. If another event overlaps, add it anyway if he asked, then mention the overlap in one line.
3. Add it, then answer in one line: what was added and when.
4. Reminders: if you do not know his preferred reminder for tests, ask once ("przypomnieć dzień wcześniej wieczorem?"), then save the answer with remember and use it from then on via alarmMinutes.

When he asks "co mam w szkole" / "kiedy sprawdziany": list from "!SZKOŁA" only, grouped by day, tests first. Say clearly if a day has nothing.
If a test is tomorrow or the day after and nothing is planned to study, mention it in one line and offer to put a study block in the calendar. Do not write plans or schedules to the calendar unless he agrees.
